# copilot integration
Read project root `.github/copilot-instructions.md` and `.ai/HANDOFF.md`. For parallel work, create an isolated worktree with `python scripts/workflow.py worktree --run RUN --task TASK`, then manually launch the installed copilot environment in that worktree. No automatic model launch is implemented. Confirm that the particular tool version recognizes its instruction file before relying on it.
