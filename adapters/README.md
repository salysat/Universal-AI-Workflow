# Assistant adapters

Generic compatibility instructions are in root `AGENTS.md`, and in `CLAUDE.md`, `GEMINI.md`, `.cursor/rules/`, and `.github/copilot-instructions.md`. The folders here are entrypoint hints, not working API adapters or auto-invoked agents. Before assuming support, check the installed assistant's current documentation/version. Agents that cannot launch separate sessions use **single-agent mode**.
