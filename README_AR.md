# Universal AI Workflow V3 + Skills Engine

حزمة **عامة** لتسليم حالة العمل بين مساعدين مختلفين، لأي مشروع برمجي أو مستند أو بيانات أو وسائط. لا تفترض أن كل مساعد يستطيع تعديل كل نوع من الملفات أو تثبيت Skills.

## التثبيت
1. انسخ الملفات إلى **نسخة عمل** من مجلد مشروعك. لا تستبدل AGENTS.md أو CLAUDE.md أو التعليمات القائمة إن وجدت؛ ادمجها يدوياً.
2. احتفظ بملفات المشروع الأصلية في Git/نسخة احتياطية، واحذف المعلومات السرية من ملفات الحالة.
3. أعطِ المساعد إذن الوصول للملفات المطلوبة وأرسل محتوى `START_PROMPT_AR.md` أو `START_PROMPT_EN.md`.
4. عند أول تشغيل يفحص المساعد الملفات الفعلية ويملأ `.ai/MANIFEST.md` و`.ai/STATE.md` (بما فيها أوامر البناء والاختبار) دون اختلاق نتائج.
5. لنقل العمل إلى مساعد آخر: انقل مجلد المشروع كاملاً مع الملفات المحدثة وأرسل برومبت البداية. الملفات وحدها لا تجعل المساعدين يتذكرون تلقائياً.

## وضعا العمل (جديد في V3)
- **Lite:** مهمة صغيرة ومحددة. يقرأ المساعد `HANDOFF.md` فقط ويحدّثه فقط. أقل استهلاكاً.
- **Full:** مهام متعددة الخطوات، أو تبديل المساعد، أو قرارات جديدة، أو تعديل أكثر من ~3 ملفات، أو حالة غير مهيأة. يقرأ ويحدّث مجموعة `.ai` كاملة.
- عند الشك استخدم Full. يمكنك فرض الوضع بنفسك.

## الحماية من الحالة القديمة والتعارض (جديد)
- كل تحديث يحمل التاريخ واسم المساعد، و`STATE.md` يحمل آخر commit. يقارن المساعد هذه القيم بالواقع قبل الاعتماد عليها.
- قبل الكتابة يعيد المساعد قراءة رأس الملف؛ إن تغيّر فإنه **يدمج ولا يستبدل**.
- `CHANGELOG.md` للإضافة فقط (الأحدث أولاً)، وعند تجاوز ~50 سجلاً أو شهرياً يُنقل القديم إلى `.ai/archive/`.

## المهارات
- `skills/find-skills/SKILL.md` دليل اكتشاف فقط. **عُطّل فيه التثبيت التلقائي** (`-y`) بإعلان سياسة في أعلى الملف.
- `.ai/skills/REGISTRY.json` يسجل لكل مهارة: المصدر، الـ commit، بصمة `sha256`، الصلاحيات، المحفزات، تاريخ المراجعة وانتهائها.
- `.ai/skills/ROUTER.md` يربط نوع المهمة بمهارة معتمدة. لا تُستخدم مهارة إلا إذا كانت معتمدة وبصمتها مطابقة ومراجعتها غير منتهية.
- أي تثبيت يتطلب إكمال `REVIEW_CHECKLIST.md` وموافقتك الصريحة على الأمر نفسه. يمكن استخدام CLI حيث يتوفر Node/npm والإنترنت.

## ملفات التوافق
- `AGENTS.md`: نقطة انطلاق عامة لـ Codex وأدوات مشابهة.
- `CLAUDE.md` و`GEMINI.md`: نقاط انطلاق لـ Claude وGemini.
- `.cursor/rules/` و`.github/copilot-instructions.md`: قواعد Cursor وCopilot.
- `AI_INSTRUCTIONS.md`: النسخة المحايدة من البروتوكول.
هذه الملفات تساعد في التوافق، لكنها لا تضمن أن كل أداة ستقرأها أو تتبعها دون تعليمات صريحة.

## الاستهلاك
المنهج يقلل إعادة قراءة الملفات والمخرجات المكررة عند استخدامه بشكل صحيح (ووضع Lite يقلل التحديثات أكثر)، لكن لا توجد نسبة توفير مضمونة. حدود المزود منفصلة عن سعة سياق المحادثة.

## V6.9.1: حارس السياق (إصلاح نفاد التوكن)

**تقسيم المهام ليس تقسيمًا لنافذة السياق.** في وضع المعاينة أو الفريق الداخلي لا يُشغّل أي وكيل خارجي، فتتراكم كل المهام والأدوار والتقارير ومخرجات الاختبارات في محادثة واحدة. أضفنا `scripts/uw_context_guard.py` وأمر `uw-context` لكل المنصات:

```powershell
py -3 scripts\uw_context_guard.py --root . check --run RUN --max-tokens 12000
py -3 scripts\uw_context_guard.py --root . brief --run RUN
py -3 scripts\uw_context_guard.py --root . prompt --run RUN
py -3 scripts\uw_context_guard.py --root . trim --run RUN --max-chars 800 --apply
```

- `brief` بدل طباعة الحالة الكاملة (قياس فعلي: 839 بايت مقابل 47,497 بايت لتشغيل من 12 مهمة).
- `check` يُرجع exit 2 مع `over_budget: true` عند تجاوز الميزانية → **توقف وسلّم**.
- `prompt` يكتب `.ai/runs/RUN/FRESH_PROMPT.md` (≤ 450 كلمة) لبدء **محادثة جديدة**.
- `trim` يقصّ الأدلة المتراكمة مع حفظ نسخة كاملة في `internal-auto.full.json`.

التفاصيل في [V6_9_1_GUIDE_AR.md](V6_9_1_GUIDE_AR.md) و[docs/CONTEXT_GUARD.md](docs/CONTEXT_GUARD.md). التقديرات هي `bytes/4` لحجوم الملفات وليست قياس المزود؛ ولا توجد أداة تزيد حصة المزود.

## V6.10: تكتب `uw-auto` فقط

صار `uw-auto` **نقطة دخول واحدة**: يولّد الخطة تلقائيًا من بنية المشروع، يوجّه المهارات المحلية المُراجَعة، يقيس السياق، ويشغّل كل مهمة في عملية/نافذة سياق/worktree مستقلة عند توفر CLI مُصادَق عليه (وإلا يسلّمك لمحادثة جديدة تلقائيًا).

```powershell
py -3 scripts\uw_autopilot.py boot
py -3 scripts\uw_autopilot.py run --run RUN          # في الوضع external
py -3 scripts\uw_autopilot.py tick --run RUN --task T01 --evidence "..."   # في الوضع inhost
```

المهارات محلية فقط بلا تنزيل أو تثبيت، والموافقات على التشغيل الخارجي تُحفظ مرة واحدة في `uw-auto.config.json` (مستبعد من Git). التفاصيل: [V6_10_GUIDE_AR.md](V6_10_GUIDE_AR.md) و[docs/AUTOPILOT.md](docs/AUTOPILOT.md).

## V6.11: بلا مساعدات خارجية — نفس المساعد يتكرر

الافتراضي الآن **لا يستدعي أي CLI خارجي**. بدلًا من ذلك يكتب `uw_autopilot.py spawn` ملف `SESSION-*.md` مستقلًا لكل مهمة (≤ 450 كلمة). في وضع `self` (إن دعمت المنصة الوكلاء الفرعيين الأصليين) تُنشأ نسخة من **نفس المساعد** لكل ملف، ولكل نسخة سياقها الخاص. في وضع `sessions` تُفتح محادثة جديدة لكل ملف، و`tick` يولّد الملف التالي تلقائيًا. الوضع الخارجي صار اختياريًا صريحًا ولا يُفعّل بمجرد كتابة `uw-auto`. التفاصيل: [V6_11_GUIDE_AR.md](V6_11_GUIDE_AR.md).
